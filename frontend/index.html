3-Tier Production Architecture

Separation of concerns: Frontend (5500) → Spring Boot (8080) → MySQL 8.0 (3306).

Tier 1 • Port 5500

Presentation Layer

Semantic HTML5 • CSS Grid • Vanilla JS ES6

  • Dynamic real-time seat headroom calculation
  • Accessible <dialog> modal & ticket toggle (1-2)
  • Client-side validation & instant duplicate warning toasts
  • Responsive desktop & mobile responsive layout
Tier 2 • Port 8080

Business Logic API

Java 17 • Spring Boot 3 • Spring Data JPA

  • Transactional capacity verification (@Transactional)
  • Duplicate email detection per workshop (HTTP 409 Conflict)
  • Strict ticket bounds (1-2 seats, HTTP 400 Bad Request)
  • REST Endpoints: POST/GET/DELETE /api/registrations
Tier 3 • Port 3306

Relational Database

MySQL 8.0 Community • InnoDB Engine

  • UNIQUE KEY uk_event_email (event_id, attendee_email)
  • Foreign Key constraints with cascade updates
  • Check constraint chk_tickets (1 OR 2)
  • ACID transactions preventing overselling during traffic bursts
